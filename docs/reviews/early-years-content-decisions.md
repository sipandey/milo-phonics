# Early Years Content Decisions

Date: 16 November 2026

This is a source review of the current picture-word content, not evidence that children recognise the images. Emoji appearance varies by device and must be checked in use.

| Word | Current picture | Context shown or heard | Decision / open review question |
| --- | --- | --- | --- |
| sat | Cat | “The cat sat on the mat!” | Keep the sentence with the picture; the cat alone does not show the action *sat*. Observe whether children understand the action. |
| at | Map pin | “Look at that shiny yellow star!” | The pin is a location symbol, not a concrete picture of *at*. Keep the spoken sentence visible after blending; consider a simple person looking toward a star illustration. |
| sap | Pine tree | “Sweet sticky sap runs down the pine tree!” | The tree gives context, but does not depict sap. Add a clear amber sap droplet or short tree-tapping animation if the asset set permits. |
| box | Box | Existing word audio | Concrete, familiar image; check that emoji rendering remains an obvious box on target devices. |
| fox | Fox | Existing word audio | Concrete, familiar image; check distinction from dog/cat pictures on target devices. |

Current implementation shows each blend's contextual sentence on the reveal card. The table records decisions and unresolved ambiguity, not child validation. Review with practitioners and families before treating these choices as settled.
